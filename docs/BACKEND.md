# 后端文档

当前版本：**1.1.0**

## 当前状态

本项目当前为**纯前端/微信小程序项目**，**没有独立后端服务**。

## 当前数据来源

- 特效、渲染逻辑：本地 GLSL / WebGL
- 偏好设置：`uni.setStorageSync`
- 暗房照片索引：本地存储
- 拍摄产物：小程序端本地文件 / 系统相册

## 当前不包含

- 独立 API 服务
- 用户系统
- 云函数
- 数据库
- 文件服务器

## 如果后续接入后端

建议至少补充以下能力：

1. 用户登录与设备同步
2. 相册云备份
3. 分享海报生成
4. 滤镜配置动态下发
5. 埋点与版本更新公告
