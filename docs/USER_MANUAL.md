# 使用手册

当前版本：**1.1.0**

## 1. 打开相机

进入小程序后默认进入相机页。

- 默认特效：`HK-Neon`
- 默认比例：`4:3`

## 2. 切换特效

在底部特效菜单中左右滑动或点击特效名称即可切换。

- 当前选中特效会高亮显示
- 切换后会自动记住，下次打开继续使用

## 3. 切换比例

点击左上角比例按钮可切换：

- `4:3`
- `1:1`
- `16:9`

切换后会自动记住。

## 4. 变焦

在相机画面中双指捏合可进行变焦。

## 5. 拍照

点击底部快门按钮即可拍照。

- 会触发快门动画
- 可播放机械音效
- 可触发震动反馈

## 6. 查看暗房

点击左下角按钮进入暗房页，可查看已经拍摄的照片。

## 7. 设置

点击右下角按钮进入设置页，可控制：

- 震动反馈
- 机械音效

## 8. 分享

当前所有页面都支持：

- 转发给好友
- 分享到朋友圈

可通过微信右上角菜单进行操作。
